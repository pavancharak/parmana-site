# Parmana Systems website

This is the **Next.js version** of the Parmana institutional authority website.

## Run

```powershell
npm install
npm run dev
```

Open http://localhost:3000

## Important

This package uses Next.js, not Vite. Do not run `npm install vite`.
It is designed to fit the existing `parmana-site` Next.js project structure.
