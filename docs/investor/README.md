# Investor deck

`Parmana-Investor-Deck.pptx` is a 16 slide Series A deck with speaker notes on every slide. It is
generated by `build-deck.cjs`, so edit the copy there and rebuild rather than hand-editing the file:

```sh
cd docs/investor
npm install
npm run build
```

Sections: Opening (title, summary), Problem (why now, the problem), Solution (Ready. Enforced.
Proven., how it works, the ₹50,000 refund example), Product (product today, differentiation, use
cases), Business (go-to-market, market, progress, team), Close (the ask, contact).

Content decisions (2026-10-06):

- Regulatory timing claims from the September investor letter (RBI, NPCI UAP, Colorado, Singapore,
  the 115-day window) are deliberately left out.
- Raise is $3-5M Series A, with the letter's three uses of funds.
- Market figures (India ₹500-1,000 crore in 2027, global $2-5B in 2030) are labelled as company
  estimates on the slide.
- Product claims follow the live site and `docs/SITE_CONTENT_VALIDATION.md`. Site copy rules apply:
  no em or en dashes, AI and agents request actions and never act as the authority.

Before each send, update the Progress slide (slide 13) with current facts only.
