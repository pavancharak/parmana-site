# Parmana Website

A responsive Next.js App Router website for Parmana, with clear product language and explanatory visuals.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

The visual direction is inspired by high quality financial infrastructure websites: restrained typography, whitespace, structured diagrams, and direct language. It does not use Stripe logos or imply an affiliation with Stripe.
