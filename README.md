# Parmana Systems Website

Premium institutional landing page focused on preserving business authority in autonomous AI.

## Run
npm install
npm run dev

## Build
npm run build

## Deploy
The project is Vite + React and can be deployed to Vercel, Netlify, or any static host.

Primary positioning:
"Keep the authority. Let AI operate autonomously."

Core promise:
"Parmana ensures autonomous AI can execute only the actions your business has authorized."
