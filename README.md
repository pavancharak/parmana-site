# Parmana site revision

This revision changes the website around one simple idea:

**People decide what autonomous AI is allowed to do. AI acts. Parmana makes sure AI stays within that limit.**

The revision removes or reduces wording that asks readers to understand specialist concepts before they understand the product.

## Main changes

- Replaced the hero with a reader-first message.
- Made the source of the limit explicit: people responsible for the institution.
- Made the boundary explicit: AI can act, but cannot set or change its own limits.
- Reworked the problem section so the reader immediately understands who decides, who acts and who checks.
- Reworked the product explanation into three simple steps.
- Reworked the architecture so it reads as a simple flow.
- Added a clear section explaining what Parmana does not replace.
- Added a full FAQ that answers the questions a business, regulator, security leader or developer is likely to have.
- Added a plain-language answer to the difference between governance, security and Parmana.
- Simplified navigation to Product, How it works, Examples, Questions and Docs.
- Updated metadata for search and link previews.
- Kept the existing visual direction rather than introducing a new visual system.

## Important scope statement

The copy does not claim that Parmana solves every AI or security problem.

It claims something narrower:

**Parmana checks autonomous actions against limits set by people before those actions reach the protected system.**

That statement should remain consistent across the site.
